# docs/

Project documentation.

- `scoring-spec.md`: the complete specification of the scoring system (criteria, terrain,
  profile weights, final score, explanations, similarity, confidence, Bayesian ratings).
- `sources.md`: robots.txt / terms checks per site.
- `data-coverage.md`: how many models have each spec and review.
- `methodology-nlp.md`: how phase 5 turns review text into criterion scores.
- `reports/phase-N.md`: one report per phase.
- `img/`: plots generated by the build (`criteria_distribution.png`).
